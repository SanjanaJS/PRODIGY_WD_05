# WeatherNow - Smart Weather Dashboard

## About the Project

This project is a weather application developed as part of my Web Development Internship at Prodigy InfoTech.

The main purpose of this project is to create a responsive, attractive, and user-friendly weather dashboard that displays real-time weather information for different cities and provides a weather forecast to help users understand current and upcoming weather conditions.

## Purpose

The purpose of this project is to demonstrate web development skills, including:

- Creating a structured webpage using HTML
- Designing the dashboard using CSS
- Fetching weather information from APIs using JavaScript
- Searching for weather information by city name
- Retrieving weather information using the user's current location
- Displaying current weather conditions and forecasts
- Creating a responsive layout for different screen sizes

## How It Works

The application allows users to search for a city and view its weather information.

Users can also use the **Use My Location** feature to retrieve weather information based on their current location, subject to browser location permissions.

The application uses the Open-Meteo Geocoding API to find city coordinates and the Open-Meteo Weather API to retrieve weather information.

The dashboard displays:

- Current temperature
- Feels-like temperature
- Weather conditions and icons
- Humidity
- Wind speed
- Atmospheric pressure
- Visibility
- Sunrise and sunset times
- 5-day weather forecast

The application also provides smart weather insights, including clothing suggestions, umbrella recommendations, and outdoor activity guidance based on weather conditions.

Users can switch between Celsius and Fahrenheit to view temperatures in their preferred unit.

If a city cannot be found, the application displays an error message asking the user to check the spelling and try again.
